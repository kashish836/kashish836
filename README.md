## 🚀 Featured Projects

### 🛡️ Relay — WhatsApp Message Notification Router
An intelligent notification system built during the **HackerRank Orchestrate — August 2026 hackathon**.

Relay classifies incoming WhatsApp messages into `Notify` · `Digest` · `Mute` — reasoning over text, images/posters, and voice notes, while adapting decisions to user preferences.

**What makes it interesting:** safety doesn't depend on the LLM. A separate **deterministic safety layer** uses rules, regex, and risk scoring to catch suspicious patterns — payment requests, OTP scams, urgency signals, sender inconsistencies.

> Personalization comes from the model. Safety comes from code.

`Python` · `Groq` · `LLMs` · `Vision Models` · `OCR` · `Rule-based Risk Engine`

---

### 🖐️ Vaani — Indian Sign Language Translator
An offline Android app that translates Indian Sign Language gestures into text and speech in real time.

- 35 gesture classes · 41K+ landmark samples
- MediaPipe hand landmark extraction
- TensorFlow / Keras model → TFLite deployment
- Flutter Android app with native MediaPipe integration via Kotlin
- Real-time text + speech output

`Python` · `OpenCV` · `MediaPipe` · `TensorFlow` · `TFLite` · `Flutter` · `Dart` · `Kotlin`

---

### 👕 Fashion Recommender
A visual recommendation system that finds visually similar fashion items from an uploaded image.

`Image → Feature Extraction → Similarity Search → Recommendations`

Built around **ResNet50**, with a **FastAPI** backend and visual web matching through the **Google Cloud Vision API**.

`Python` · `PyTorch` · `ResNet50` · `FastAPI` · `Google Cloud Vision` · `Computer Vision`

---

### 🌐 AI Portfolio — *Chapter One: The Bookstore*
A personal portfolio designed around a bookstore / reading experience rather than a conventional developer portfolio — built to feel interactive while staying professional and easy to navigate.

`React` · `TypeScript` · `Three.js` · `Framer Motion`
