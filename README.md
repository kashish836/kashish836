## 🚀 Featured Projects

### 🛡️ Relay — WhatsApp Message Notification Router

An intelligent notification system built during the **HackerRank Orchestrate August 2026 hackathon**.

Relay classifies incoming WhatsApp messages into:

`Notify` · `Digest` · `Mute`

It can reason over **text, images/posters and voice notes**, while adapting decisions to user preferences.

**What makes it interesting:**
Safety doesn't depend on the LLM.

A separate deterministic safety layer uses **rules, regex and risk scoring** to detect suspicious patterns such as payment requests, OTP-related messages, urgency signals and sender inconsistencies.

> **Personalization comes from the model. Safety comes from code.**

**Tech:** Python · Groq · LLMs · Vision Models · OCR · Rule-based Risk Engine

---

### 🖐️ Vaani — Indian Sign Language Translator

An offline Android application that translates **Indian Sign Language gestures into text and speech** in real time.

* 35 gesture classes
* 41K+ landmark samples
* MediaPipe hand landmark extraction
* TensorFlow / Keras model
* TFLite deployment
* Flutter Android application
* Native Android MediaPipe integration through Kotlin
* Real-time text + speech output

**Tech:** Python · OpenCV · MediaPipe · TensorFlow · TFLite · Flutter · Dart · Kotlin

### 👕 Fashion Recommender

A visual recommendation system that finds visually similar fashion items from uploaded images.

**Pipeline:**

`Image → Feature Extraction → Similarity Search → Recommendations`

Built around **ResNet50**, with a backend powered by **FastAPI** and visual web matching through **Google Cloud Vision API**.

**Tech:** Python · PyTorch · ResNet50 · FastAPI · Google Cloud Vision · Computer Vision
